# How To Use This

This directory contains a collection of scripts for testing API endpoints before direct integration.

## Purpose

These scripts allow you to:
- Test endpoints in isolation
- Validate request/response formats
- Debug API behavior without full integration
- Verify functionality before implementing in the application

## Usage

Run individual scripts to test specific endpoints. Each script simulates API calls and displays results.

## Benefits

- Faster iteration during development
- Reduced integration issues
- Clear endpoint documentation
- Easy troubleshooting
